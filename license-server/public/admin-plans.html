管理员登录

后台仅使用独立管理员密码。建议通过 HTTPS + WAF / IP 白名单访问。

权益限制总开关 Entitlement limits

关闭后，所有已登录且状态正常的用户不再受权益到期时间、用户等级、设备数量及并发窗口上限约束；客户端隐藏等级、权益、升级、签到与分享奖励入口。登录验证、账号状态及会话安全仍然生效。

用户等级

新用户注册后默认普通用户。这里可设置新用户初始有效天数，以及普通、深度、重度用户的设备/窗口权益和深度、重度升级价格。
