从安装到日常使用

按步骤设置一次，
之后正常聊天。

这份教程只保留用户需要操作的内容。安装、登录、选择偏好并开启 GPTWork 后，就可以像平时一样使用 ChatGPT。

01

安装 GPTWork

Windows 使用正式发布的 GPTWorkSetup-x64.exe；Linux 使用对应的 deb。安装完成后按安装提示启用浏览器扩展，并完全重启浏览器。

WindowsLinuxChrome / Edge下载 GPTWork
02

检查安装状态

打开 GPTWork。状态显示正常即可继续；如果提示组件离线或安装异常，先使用修复功能或重新安装，不需要手动判断内部原因。

03

登录 GPTWork 账户

使用 GPTWork 账户登录。账户中心可以查看当前权益、管理已绑定设备、退出旧会话和修改密码。

04

选择模型与推理偏好

在设置中选择首选模型和需要的推理强度。建议只选择你实际会使用的配置，日常会更清楚。

首选模型推理强度保存设置
05

开启 GPTWork

确认状态正常后开启 GPTWork，然后回到 chatgpt.com 正常输入并发送消息。无需在每轮聊天前重复设置。

06

遇到异常时再诊断

如果页面状态、模型表现或插件状态与预期不一致，可以使用自动验证和运行日志。诊断结果可用于排查问题，不需要用户理解底层实现。

07

保持更新

建议优先使用正式发布版本。版本发布页只展示 Windows、Linux 等用户实际需要的安装包；安装包已经包含对应版本的扩展文件。
