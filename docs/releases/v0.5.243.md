# GPTWork v0.5.243 · Astra 单次请求修复

v0.5.242 的 private-request-hook.js 覆盖 network-monitor.js 的 Fetch 入口，但仅为自动验证事务委派。Astra 调试请求被普通私有处理器截走，因此可能有真实网络请求，却没有 Astra 转发证据。

修复为：只有显式启动且尚未认领的 Astra 探针，且最后一条实际发送的用户消息严格匹配固定测试文本，才交由原有 Fetch 专用处理器。其他请求继续走私有引擎。历史消息中出现固定测试文本不再能触发认领。一次 Fetch 成功认领后不重复改写。

实机验收仍需导出 JSONL 和调试结果，分别核对 astra_debug_fetch_claimed、astra_debug_request_forwarded、HTTP/SSE 终态和响应模型元数据。自动化测试通过不代表真实 ChatGPT 后端已接受 Astra。
