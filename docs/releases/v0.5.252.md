# GPTWork v0.5.252

## 修复：Chrome 110 响应超时闹钟兼容性

- 保留扩展声明的最低 Chrome 版本 110。
- Chrome 111 起，`chrome.alarms.create()` 支持 Promise；Chrome 110 不提供该 Promise 返回值。新增兼容封装，同时处理旧版 `undefined` 返回和新版 Promise 拒绝，避免对 `undefined` 直接调用 `.catch()` 导致请求监听逻辑抛错。
- 初始 120 秒响应证据期限与下游流 30 秒空闲宽限统一使用兼容封装。
- 增加回归检查，确保 Chrome 110 最低版本声明与闹钟 Promise 兼容逻辑同时保留。

## 发布说明

本版是 v0.5.251 的兼容性修正版。v0.5.251 的响应证据超时状态恢复功能保持不变；本版只修复其 Chrome 110 闹钟 API 返回值兼容问题。
