# GPTWork v0.5.60

This release improves the default feature state for newly opened ChatGPT tabs and makes locked-model sources explicit in Settings.

- New ChatGPT tabs now start with both Work mode and Model Lock enabled by default while keeping each tab independent.
- Explicit per-tab on/off choices remain authoritative, and the global GPTWork Master switch still controls whether GPTWork is active.
- Locked-model cards now distinguish `手动添加 / Manual` from `自动获取 / Auto discovered`.
- Automatically discovered models continue to show their network request/response confirmation evidence.
- Added regression coverage for the new default-on behavior and model-source labels.

This release carries the feature changes merged in PR #197 and bumps the production version from 0.5.59 to 0.5.60.
