# GPTWork v0.5.225 — GPT Thinking sibling lock equivalence, singular floating locked model

## Explicit requested behavior
1. Treat `gpt-6-thinking` and `gpt-6` as equivalent for model-lock policy decisions, also future numeric GPT series such as `gpt-6.5-thinking`/`gpt-6.5` and `gpt-7-thinking`/`gpt-7`.
2. Rename the bottom-right floating **请求模型** field to **锁定模型**, showing only the single model actually chosen/sent for the observed request—not the whole multi-select allow-list.

## Implementation
- Introduce one deliberately narrow base-model family rule `^gpt-\\d+(?:\\.\\d+)*-thinking$`, applied **only to lock comparison and its floating representation**, not generic model normalization.
- Mirror the rule in native verifier, extension policy and guard, response-history policy filtering, and the actual intercepted outgoing request allow-list. Separate Sol / Astra / Instant / different GPT versions and extended suffixes remain distinct.
- Native verification result and all recorded request and response model IDs remain **unchanged actual network evidence**; `gpt-6-thinking` in a real response remains visible as `gpt-6-thinking`.
- Floating `锁定模型` uses a single actual formal request's final model, normalizes only to the lock family for that field, and relies on the immutable per-request allow-list where provided. Before a real request it says **等待请求**; without an active lock it says **未锁定**; if actual sent model was not allowed, it reports the mismatch instead of inventing the desired model.
- Model discovery retains exact raw protocol IDs for two-stage verification; ordinary Chat UI remains read-only.

## Evidence and validation limits
- Regression tests cover 6, 6.5, 7 and future dot-separated numeric versions, negative cases for Astra/Sol/Instant and mismatched versions, model-lock network passthrough, real response preservation, no-lock behavior, multiple selected locked models, and Rust strict model verdict.
- Tests prove implementation behavior only. Browser/server acceptance of a particular future model cannot be inferred from its name.
