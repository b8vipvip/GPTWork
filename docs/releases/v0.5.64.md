# GPTWork v0.5.64

## Security

- Complete capability lease Phase B/Phase C across the account service, extension, Native Core, and private engine.
- Make the account service authoritative for entitlement, device admission, browser/extension identity, and admitted window bindings before a protected capability lease is issued.
- Keep the short-lived lease opaque and service-worker-memory-only in the extension; protected private-engine entry points fail closed when the lease is missing or invalid.
- Verify Ed25519 signatures plus issuer, audience, lifetime, feature, device, browser, extension, and window bindings inside the private engine.
- Add a production release gate that blocks private-engine builds when no capability-lease verification key is configured.
- Add safe Ed25519 deployment-key generation and regression coverage without exposing the private signing key.
- Pin the deployed production capability-lease public key into private-engine release builds; the private signing key remains only on the GPTLock account service.

## Deployment

- Production capability-lease issuer is enabled at `https://gptlock.mv3.cn` with a 300-second lease lifetime.
- Release binaries are cryptographically bound to the matching production Ed25519 public key.
