# GPTWork v0.5.251

## 修复：响应证据等待状态超时恢复

- 普通聊天请求开始后，增加 120 秒响应证据等待期限，避免右下角状态永久停留在“等待确认”。
- 超时任务按标签页和请求 ID 独立关联；新请求会清理已被替代请求的旧超时任务，过期事件不会误更新后续请求状态。
- 初始流交接信息视为临时证据；下游 SSE/WebSocket 最近仍有活动时，最多按 30 秒空闲窗口给予额外宽限。
- 超时且没有新的下游活动时，将状态明确标记为 `unverified`，并解释“请求未被阻断，但模型尚未确认”。不会把超时伪装成模型验证成功，也不会因此阻断聊天。
- 收到终态/下游证据、监控器断开或标签页关闭时，清理对应超时任务。

## 验证范围

- 增加回归检查，覆盖请求 ID 绑定、旧请求超时隔离、等待状态自愈、下游流空闲宽限和 UI 文案。
- CI 通过后再由 Release 工作流从同一提交的精确 SHA 构建并核验 Windows 安装程序与 Linux deb。
- 本版解决的是状态机长期等待问题；超时本身不证明服务端实际执行模型，也不等同于上游响应已成功完成。
