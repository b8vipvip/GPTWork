# GPTWork v0.5.59

Hotfix release for the in-place updater regressions found after v0.5.58.

- Fix update message ownership so `GPTWORK_UPDATE_STATUS_GET`, `GPTWORK_UPDATE_CHECK`, and `GPTWORK_UPDATE_INSTALL` are handled by the updater authority instead of racing the generic background message router.
- Re-run background initialization after Master is restored during an in-place extension reload, preventing a stale Master-off initialization from leaving Native Core status behind.
- Reconcile stale post-install recovery timeout state automatically once the extension, Native Core, and content runtimes are healthy.
- Keep the popup at its intended width and wrap long recovery diagnostics instead of allowing JSON/error text to stretch the UI.

This release carries the runtime fixes merged in PR #195 and bumps the production version from 0.5.58 to 0.5.59.
