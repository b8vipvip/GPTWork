锁定模型 Locked models

这里保存“模型锁定”功能使用的模型列表。Work 模式有独立的 GPT-5.6 Sol 及以上模型规则；两个功能同时开启时会合并两边允许的模型。

允许的推理强度 Allowed reasoning levels

若正式请求顶层已经存在可识别的推理强度字段，GPTWork 会把不允许的值改为优先推理强度；不会凭空添加网页当前没有发送的字段。选择后立即同步。

响应确认（可选） Response verification

请求锁定本身也需要 Chrome/Edge 的“调试程序”权限。打开同一标签页的 DevTools 可能抢占调试连接；此时 GPTWork 会告警，但不会把日常聊天卡死。

The request interceptor also uses the browser debugger permission. DevTools may detach GPTWork from the same tab; GPTWork fails open with a warning.

处理模式 Enforcement mode

请求锁定优先保证正常聊天。核心离线、页面识别缺失、响应字段缺失或推理强度确认异常只告警；只有与当前最新正式请求关联、且响应明确确认实际模型不在锁定列表时，强制模式才阻断后续发送。
